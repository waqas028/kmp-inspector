KmpInspector

In-app debugging for Compose Multiplatform. A live prototype — tap rows, switch tabs, expand JSON, edit cells.

Where this starts

Your library today is a draggable FAB and an empty InspectorScreen. Everything here is what goes inside that Scaffold, so nothing below fights the code that exists.

The skin

Material 3 structure, density and behaviour; Classical's serif headings, hairline rules and gold-as-stroke carried onto a warm near-black. Material Symbols throughout, JetBrains Mono for every technical value.

What is here

All six sections, populated and empty: Network, Database, Background Work, Logs, and Crashes & Exceptions, each with its first-run state. Still outstanding: the light theme.

Three places your brief argues with itself
Bubble opacity vs. accessibility. A 40%-opacity control cannot meet 4.5:1, and a badge on a translucent surface is unreadable. Resolution: the resting tab is decorative and non-informational; the moment there is unread activity or a crash it goes fully opaque, and the badge never renders below full opacity. Contrast rules apply to the opaque states.
Dynamic color vs. no colour-only status. If tonal palettes come from the user's wallpaper, you cannot promise any status hue survives. Resolution: status is a glyph plus the literal code plus the word; colour is the third signal, drawn from a fixed debug palette that ignores dynamic color. Dynamic color is applied to chrome only — app bar, nav, ripples.
Global search across seven sections. One field that means seven different things is a worse tool than a per-section filter. Resolution: search is scoped to the active tab and says so in its placeholder; a cross-section search would need result grouping and its own screen.

1
Resting = half off the edge, 40% opaque. Two thirds of a 56dp circle hangs outside the viewport, so it covers 18dp of the host app instead of 56. Touch-down restores full size and opacity before the tap resolves, so the target you actually hit is the full 48dp circle.
2
Snap is horizontal only. Vertical position is kept exactly where the finger left it. Snapping to the nearest of four edges would put the bubble over a top app bar or a bottom nav — the two places host apps keep their own controls.
3
The badge is the exception to the transparency. Unread counts render at full opacity on an opaque chip, and the bubble itself goes opaque whenever the count is non-zero. A translucent number is not a number.
4
A crash is not just red. The glyph changes to a filled error mark, a slow halo pulses twice, and the badge reads the exception count — three signals, so the state survives a red-blind developer and a greyscale screenshot alike. Try the button under the frame.

Why it is like this
1
Header carries the session, not a logo. Process, build variant and capture uptime are the first things a developer checks against, and they make screenshots self-documenting. Close is a 48dp target in the thumb-reachable corner on the phone, top-right on desktop.
2
Search is scoped and says so. The placeholder names the active tab, so the field never lies about its reach. Typing filters immediately — no submit — because every dataset here is local and small.
T
Tabs scroll rather than wrap or collapse. Five or six sections will not fit 380px, and a "more" menu hides exactly the section you need. Icon plus label keeps them recognisable at a glance, and selecting a tab scrolls it into view so the gold underline is never off-screen. Background Work only exists when the platform is Android — switch platform above and watch it leave.
3
Filters are chips, not a menu. Errors-only is the most-used view in any network log; it should be one tap, permanently visible, with its count on the chip. Every chip, level letter and toggle in the inspector draws a 32dp pill inside a 48dp hit area — the chrome stays quiet, the target passes. In Compose that is minimumInteractiveComponentSize or explicit padding on the clickable, not a bigger shape.
4
Two lines per row, six facts. One line cannot hold method, path, status, duration, size and time at 380px without truncating all of them. Line one identifies the call, line two measures it. Rows are 64dp, above the 48dp minimum.
5
Status is a glyph, a number and a colour. A bordered mark — check, recycle, bang, cross — sits next to the literal code, so the state reads in greyscale and to a colour-blind eye. Paths truncate from the left with a leading ellipsis, since the tail is the part that differs; the budget grows with the pane.
6
The empty state contains the fix. Set Data to "First run" above: the panel names the plugin, shows the two lines of setup, and offers to copy them. An empty list that only says "nothing here" wastes the one moment the developer is looking for instructions.
7
The URL wraps; it never scrolls sideways. Full host and path break across lines in mono. Below them, one tabular line holds sent size, received size, duration, protocol and time — the numbers you quote in a bug report.
8
Copy-as-cURL is peer to the tabs, not buried. It is the single most-used action in a network inspector. Tapping it reveals the exact command in a pinned strip so you can see what went to the clipboard before pasting it into a terminal.
9
JSON collapses by node, and arrays collapse by default past the first item. Whole-row tap targets are 36dp tall with the caret at the left; keys take the accent, strings a sage, numbers gold, null a dimmed italic. Collapsed nodes keep their child count, which is often all you needed.
10
Header row and first column both freeze. Scrolling right in a wide table is useless if you lose which row you are on, so the primary key stays pinned while the rest slides. Column type sits under the name in small grey — it decides how a value should be read.
11
Three awkward values, three treatments. NULL is a dimmed italic keyword, never an empty cell. A BLOB shows type and byte size, not mojibake. Long text clips to one line with an ellipsis and opens in full in the editor — tap any cell to see it. Editing is a sheet, not an inline field, because a phone keyboard would cover the grid.
12
SQL results land in the same grid. One presentation for browsing and querying means one component to build and one thing to learn. Tap SQL in the header, edit the statement, Run. Errors report above the grid, and the previous result stays on screen.
13
Level is a floor, not a set of checkboxes. Five independent toggles is five taps to answer "show me warnings and worse". Tapping W means W and E; the letters below the floor grey out so the exclusion is visible. Letters, not colours, name the level.
L
Metadata above, message below, nothing sideways. Level, time and tag ride a compact first line; the message wraps freely underneath in mono with overflow-wrap:anywhere, so a 300-character warning or a raw JSON error body stays readable without a horizontal scrollbar. Try the ImageLoader warning.
L
Tailing is a state you can see, and search does not stop it. The pill reads Tailing or Paused rather than showing an ambiguous icon; the footer says whether the buffer is live or frozen at a timestamp. Tag filter is a native select because tag lists grow past what chips can hold. The pill is pinned outside the scrolling filter row, so it is reachable at 380px without discovering a sideways scroll.
14
Fatal and non-fatal are one list with a filter, not two lists. Order in time is what tells you a handled exception preceded the crash. The FATAL / CAUGHT badge carries a glyph and a word, so severity never rests on red versus amber, and repeats collapse into a ×count chip.
15
Type, message and thread before the trace. The exception class sets in mono, the message in the body face — it is prose and reads faster that way. Any Caused by gets its own bordered line above the trace, because the root cause is usually the answer.
16
App frames are pulled left and marked; framework frames are indented and dimmed. Three signals again — border, tint, brightness — so the frames you can act on are findable in a greyscale screenshot. Frames wrap rather than scroll, and framework noise can be hidden entirely. Copy and Share sit at the top, where you reach for them after reading.
17
State first, name second, timings third. The question is almost always "did it run, and when does it run again", so each row leads with a glyph-plus-word state badge, then the worker name, then last and next run as a two-line tabular pair. Attempt count sits opposite the badge, since attempts only matter when something failed.
18
Detail is four labelled blocks in read order. Schedule, constraints as chips reading like the enum values they are, then input and output data as key–value tables, then the failure reason with its own accent rule. Output is omitted rather than shown empty when a job has not produced any. Open SyncOrdersWorker for the failed case and ExportAnalyticsWorker for a cancellation.
W
The tab does not exist off Android. Switch Platform above: rather than showing an empty or disabled section on iOS and desktop, the tab is absent, so the tab bar always reflects what the platform can actually report.
Switch Width above to see the master–detail change: at 380 detail replaces the list, at 768 a 300dp list sits beside it, at 1440 the list is fixed and the detail pane takes the rest.
